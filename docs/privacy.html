개인정보처리방침

모투(iOS 앱) · 시행일 2026년 11월 16일

모투는 사용자의 개인정보를 수집하지 않습니다. 회원가입이나 로그인이 없고, 개발자가 운영하는 서버도 없으며, 광고·분석·추적 도구를 쓰지 않습니다.

1. 기기에만 저장하는 정보

  • 닉네임, 꾸미기 아이템 해금·장착 상태, 승리 횟수, 직접 추가한 벌칙 목록

이 정보는 사용자의 기기 안에만 저장되고 개발자에게 전송되지 않습니다. 앱을 지우면 함께 지워집니다.

2. 함께 플레이할 때 오가는 정보

  • 근처 플레이: 같은 Wi-Fi나 가까운 거리의 기기끼리 직접 연결합니다(로컬 네트워크 권한 사용). 닉네임, 꾸미기, 입력한 단어, 점수가 같은 방의 참가자 기기로만 전달됩니다. 연결은 방 코드로 암호화됩니다.
  • 인터넷 플레이: Apple의 Game Center로 친구를 초대하고 연결합니다. 이때 Game Center 계정 정보는 Apple이 처리하며, Apple의 개인정보 처리방침을 따릅니다. 게임 중 오가는 정보는 근처 플레이와 같습니다.

개발자는 이 정보를 받거나 보관하지 않습니다.

3. 제3자 제공

개인정보를 수집하지 않으므로 제3자에게 제공하는 정보도 없습니다.

4. 아동의 개인정보

모투는 연령과 관계없이 어떤 개인정보도 수집하지 않습니다.

5. 방침의 변경

이 방침이 바뀌면 이 페이지에 바뀐 내용과 시행일을 알립니다.

6. 문의

개인정보와 관련한 문의는 GitHub 이슈로 남겨 주세요.
