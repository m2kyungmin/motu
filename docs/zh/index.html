Motu：成语接龙·词语接龙

和朋友用手机玩接龙 · 个人赛·团队赛 · iOS

Motu 是一款和朋友用手机一起玩的多人聚会接龙游戏。后一个词要以前一个词的最后一个字开头，应用会用内置词典即时判断你输入的词是否有效。附近的朋友直接加入，远方的朋友通过 Game Center 邀请，无需注册，没有广告。

两种玩法

  • 词语接龙（默认）：用最后一个字接下一个词，例如 学生 → 生活 → 活动。
  • 成语接龙（可选）：只接四字成语。成语以词典收录为准，词典里没有的成语不会被判定为有效。

同音接龙（可选）

打开后，下一个词的第一个字只要与上一个词最后一个字读音相同（不计声调）即可，例如 学生 → 声音。关闭时必须是同一个字。简体字和繁体字都可以输入。

和朋友一起玩

  • 附近的朋友：在房间列表中点一下房间就能加入，没有房间码。
  • 远方的朋友：通过 Game Center 邀请好友一起玩，双方都需要登录 Game Center。
  • 个人赛与团队赛：团队赛可分为 2 至 4 队，轮流接词，按队员得分合计比高低。

一个人也能练

练习模式里有 1 至 5 级的“Motu 机器人”。级别越高，接得越长、越不容易出错。

房间的语言

房间的语言（韩语、日语、中文）由房主选择。应用界面会跟随设备的语言。

惩罚游戏

输的人受什么惩罚，交给游戏来决定。中文、日语、韩语都能玩。

  • 传炸弹：传着一部手机轮流接词，炸弹爆炸时手里拿着的人受罚。语言可以在界面上选择。
  • 弹珠轮盘：大家输入词语来放入或取出弹珠，再让剩下的弹珠滚下去，决定谁受罚。使用房间的语言。
  • 惩罚转盘：从内置惩罚中选一个，或自己写一条，然后转动转盘。

常见问题

有可以和朋友用手机一起玩接龙的应用吗？
Motu 就是这样的应用。附近的朋友可以从房间列表直接加入，远方的朋友可以通过 Game Center 邀请，一起玩接龙。这是一款 iOS 游戏。
词语接龙怎么玩？
后一个词要以前一个词的最后一个字开头，例如 学生 → 生活 → 活动。应用会用内置词典即时判断你输入的词是否有效。
成语接龙怎么玩？
在选项里打开成语接龙后，只能接四字成语。成语以词典收录为准，词典里没有的成语不会被判定为有效。
什么是同音接龙？
打开后，下一个词的第一个字只要与上一个词最后一个字读音相同（不计声调）即可，例如 学生 → 声音。关闭时必须是同一个字。
可以输入繁体字吗？
可以。用繁体字输入的词也会被接受，例如输入 學生 与输入 学生 一样有效。游戏界面里显示的是简体字。
一个人可以玩吗？
练习模式里有 1 至 5 级的 Motu 机器人，级别越高，接得越长、越不容易出错，一个人也能练。
怎么判断词语是否有效？
用内置的 CC-CEDICT 词典即时判断。它收录的是汉英词典里的词条，不是权威的汉语词典，可能缺少部分常用词或成语，也可能收录一些不常见的词。专有名词、姓氏、缩写和部分不雅词条已被过滤，但无法保证没有遗漏。
可以分队玩吗？
团队赛可分为 2 至 4 队，轮流接词，按队员得分合计比高低。
需要注册或登录吗？
不需要。没有广告，也不收集个人信息。只有联网对战需要每台设备登录 Game Center。
也能玩韩语或日语接龙吗？
可以。房间的语言（韩语、日语、中文）由房主选择。传炸弹、弹珠轮盘、惩罚转盘等惩罚游戏也支持中文、日语和韩语。
聚会时可以用来玩惩罚游戏吗？
可以。应用里有传炸弹（传着一部手机轮流接词）、弹珠轮盘（用词语放入或取出弹珠再滚动）和惩罚转盘（选一个惩罚来转），中文、日语、韩语都能玩。
有安卓版吗？
目前只有 iPhone（iOS）版。

遇到问题时

看不到附近朋友的房间。
两台设备需要在同一个 Wi-Fi 下，或者距离很近。请在 设置 > 隐私与安全性 > 本地网络 中确认已允许 Motu，并确保所有参与者使用相同版本的应用。

联网对战无法进行。
所有设备都需要登录 Game Center，并且互相是 Game Center 好友才能邀请。

我输入的词不被接受。
可能是词典里没有这个词，或者首字不对，或者这个词已经出现过。也请检查房间的选项设置。缺少的词欢迎通过 Issue 反馈。

联系与反馈问题

请在 GitHub Issues 留言。写明设备型号、iOS 版本，以及在哪个界面做了什么，我们能更快修复。
